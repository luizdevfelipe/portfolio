Sobre mim

Olá! Meu nome é Luiz Felipe de Almeida Fávaro e sou desenvolvedor web com foco em back-end. Minha trajetória na programação começou com o domínio das bases — HTML, CSS e JavaScript — e, desde então, venho me aprofundando no desenvolvimento de aplicações web completas, compreendendo tanto a lógica de negócio quanto a arquitetura por trás de sistemas modernos.

Formação

Sou estudante de Engenharia de Computação, onde tenho contato direto com fundamentos sólidos da computação, arquitetura de sistemas e desenvolvimento de software.
